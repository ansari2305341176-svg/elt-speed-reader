# ELT Speed Reader

An interactive English reading-skills challenge for practising skimming and scanning.

## Run locally

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.

No account, email confirmation, environment variables, or database setup is required.

## The challenge

- Warm up with two questions about a university notice.
- Complete six timed reading questions across beginner, intermediate, and advanced levels.
- If an answer is incorrect, reread the passage and try again. The report scores only your first answer.
- Review first-try accuracy, skimming and scanning scores, correct-answer streak, reading time, and answer time.
- Get recommendations based on the results and try the short revision activity.

Challenge results stay in the current browser session and are not uploaded or saved to a database.
